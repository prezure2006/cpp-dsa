## Prefix Sum Approach

Here we will use a freq array to store that till this no how many odd no we have seen to get the subbray till that number and also it has n+1 elements where n is the size of the array why bcz we have to have a satrting index to get all the subarrays.

- When we have exactly k odd numbers from the start of the array, we need to count this as a valid subarray. Without {0: 1}, when odd_count = k, looking up prefix_count[k - k] = prefix_count[0] would return 0 instead of 1.

```

class Solution {
public:
// this was prefix sum approach and there is one more approach which is two pointer
    int numberOfSubarrays(vector<int>& nums, int k) {
        int n= nums.size();
       vector<int> freq(n+1 ,0);
       int ans =0;
       freq[0]=1;// to avoid missing subarrays
       int odda = 0;

       for (int &num : nums){
        odda += (num&1);
        if(odda-k >=0){// if we substract no of odd from k do we have anthing like 0 odd numbers
    ans+=freq[odda-k];

        }
        freq[odda]++;
       }
       return ans;
    }
};
```

TC -O(n)
SC - O(1)

## Sliding Window Two pointer Approach

- Here we are using window to calculate the no of subarrays

```
class Solution {
public:
// this was prefix sum approach and there is one more approach which is two pointer

have 2 pointer Move the left when you have got onewindow to get the other window and move the right pointer after every iteration
    int numberOfSubarrays(vector<int>& nums, int k) {
    int i =0;
    int j =0;
    int cntOdd = 0;
    int ans = 0;
    int prevCount = 0;
    int n = nums.size();

    while(j<n){
       if(nums[j]%2==1){
        cntOdd++;
        prevCount=0;
       }
while(cntOdd == k ){
    prevCount++;
    // removing the previous element
    if(nums[i]%2 ==1){
        cntOdd--;
    }
    i++;
}
     ans +=prevCount;
     j++;
    }
    return ans;
    }
};

TC-O(n)
SC -O(1)
```
