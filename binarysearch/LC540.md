540. Single Element in a Sorted Array

[Approach]
1> Check the ends The starting end and the ending end is equal to is previous or next or not and in the for loop start form 1 and end at n-2 and check are the equale to there neighbouign elements if yes ans is -1 else Return that no

[Code]

```
class Solution {
public:
    int singleNonDuplicate(vector<int>& nums) {
        int n = nums.size();
        // If the nums is itslef of size 1
        if (n==1){
            return nums[0];
        }
        // If the non Duplicate is at Start
        if(nums[0] != nums[1]){
            return nums[0];
        }
       // If the non Duplicate is at the end.
       if(nums[n-1] != nums[n-2]){
        return nums[n-1];
       }
       for (int i =1;i<n-1;i++){
        if(nums[i] != nums[i-1] && nums[i] != nums[i+1]){
            return nums[i];
        }
       }
       return -1;
    }
};

```

[Complexity]
Tc - O(n) In worst case in best it could be O(1);
Sc -- O(1)

[2nd Approach]
The xor Method Loop One time.
Xor every element in the end the element who is there one time will Come

```
class Solution {
public:
    int singleNonDuplicate(vector<int>& nums) {
      int n = nums.size();
      int ans = 0;
      for (int i =0;i<n ; i++){
ans = ans ^ nums[i];
      }
      return ans;
    }
};
```
